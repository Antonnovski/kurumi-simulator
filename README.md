# YEN FX LAB v0.12.1

100万日元虚拟本金、多货币对交易的中文FX模拟游戏。纯浏览器界面、零npm依赖、合成行情，不连接真实交易账户。

## Windows便携版

1. 下载Release中的 `YEN-FX-LAB-v0.12.1-Windows-x64.zip`，解压到固定目录。
2. 双击 `Start-Game.cmd`，优先以Edge/Chrome独立游戏窗口打开；否则使用默认浏览器。启动控制台保留运行结果和访问地址。
3. 退出时双击 `Stop-Game.cmd`，只关闭本目录启动的游戏服务。

包内包含Node.js运行环境，无需安装Node或联网。不要直接从压缩包内打开启动脚本；不能直接双击HTML。首次启动通常使用 `http://127.0.0.1:4173`，端口冲突时尝试4174–4193，重复启动复用本目录服务。游戏仅监听本机回环地址。

存档保存在当前浏览器的当前网址中；线上版与本地版的存档互不共享，端口或浏览器改变会使用独立存档。资金、游戏行情与新闻都可离线生成。总结导出为PNG。v0.12.1修复启动后无可见反馈：启动和错误信息保留在控制台及 `.local/startup.log`；浏览器窗口没有自动出现时可手动打开打印出的地址。

关闭服务前暂停行情，关闭游戏标签页会自动保存；本地服务不收集账户数据。

## 从源码运行

需要Node.js 22或以上版本，在项目目录运行：

```shell
node server.js
```

也可用 `npm start`；无需 `npm install`。Windows源码版可以直接双击 `Start-Game.cmd`，脚本会寻找已安装的Node。macOS/Linux运行上面的命令即可。默认地址为 `http://127.0.0.1:4173`，可通过 `node server.js --port 4180` 指定端口。

## 玩法

- USD/JPY、EUR/JPY、GBP/JPY、AUD/JPY可同时持有多空，账户盈亏与保证金统一以日元计算。
- 市价、限价、突破、OCO双向突破、止损/止盈、移动止损、部分平仓、风险预算与1%风险模板。
- 自由交易与120模拟分钟挑战局；每局任务、收益/回撤/开仓保护评分、结算和PNG交易总结。
- 前10模拟分钟实时指导、K线历史浏览、各仓位浮盈小图、常驻其他币种简报。
- 30种随机虚构事件、六类冲击参数、共同事件跨币种联动、首次新闻与二次追踪新闻。
- 标准25倍与游戏40倍挑战规则。梭哈使用约85%可用资金，预留缓冲与费用；亏损仍可能触发强平。
- 每第三局USD/JPY包含一个随机极端行情。虚拟救急借款按游戏时间复利，支持提前还款，到期缺款结束本局。

## 验证和构建

```shell
node --test tests/*.test.js
node scripts/balance-v10.mjs
```

81项测试覆盖共同事件时机、币种响应、存档恢复、交易/保证金/贷款/结算和本地服务。3,000次120分钟持仓模拟用于检查收益分布，不承诺收益上下限。事件说明见 [EVENTS.md](EVENTS.md)，本轮样本见 [BALANCE-V12.md](BALANCE-V12.md)。

在Windows上生成含运行环境的便携包：

```powershell
powershell -File scripts/package-windows.ps1 -NodePath C:\nodejs\node.exe -Destination C:\build\yen-fx-v12
```

该打包步骤联网获取对应Node版本的官方许可证；打包后的程序运行不依赖网络。运行环境不提交到源码仓库。程序不依赖外部字体、CDN、行情API或账号登录。

## 文件

`dist/` 是离线前端；`dist/engine.js` 管理交易；`dist/market.js` 管理各市场；`dist/events.js` 是共同事件指挥器和事件库；`server.js` 是本地静态服务；`tests/` 为自动化测试。

所有新闻为游戏生成的虚构资讯。事件响应、相关性、掉期与成交深度参数未按真实市场校准，仅模拟部分现实机制，不宣称完整复制监管或券商规则。Windows启动脚本为中文；界面适配桌面、平板和手机。

Node运行时采用其官方许可证，便携包中附有 `runtime/LICENSE.node`。本仓库暂未添加游戏源码的开源许可证。
