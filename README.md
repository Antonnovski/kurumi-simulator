# 久留美模拟器 V1.0.1

100万日元虚拟本金、多货币对交易的中文FX模拟游戏。纯浏览器界面、零npm依赖、合成行情，不连接真实交易账户。

## Windows便携版

1. 下载Release中的 `kurumi-simulator-v1.0.1-Windows-x64.zip`，解压到固定目录。
2. 双击 `Start-Game.cmd`，优先以Edge/Chrome独立游戏窗口打开；否则使用默认浏览器。启动控制台保留运行结果和访问地址。
3. 退出时双击 `Stop-Game.cmd`，只关闭本目录启动的游戏服务。

包内包含Node.js运行环境，无需安装Node或联网。不要直接从压缩包内打开启动脚本；不能直接双击HTML。首次启动通常使用 `http://127.0.0.1:4173`，端口冲突时尝试4174–4193，重复启动复用本目录服务。游戏仅监听本机回环地址。

存档保存在当前浏览器的当前网址中；线上版与本地版的存档互不共享，端口或浏览器改变会使用独立存档。资金、游戏行情与新闻都可离线生成。总结导出为PNG。启动后保留可见反馈：启动和错误信息保留在控制台及 `.local/startup.log`；浏览器窗口没有自动出现时可手动打开打印出的地址。

自由局可暂停；20分钟局从点击开始或首次成功下单起按现实时间倒计时，关闭页面和刷新均不延长期限，关闭标签页会保存。本地服务不收集账户数据。

## 从源码运行

需要Node.js 22或以上版本，在项目目录运行：

```shell
node server.js
```

也可用 `npm start`；无需 `npm install`。Windows源码版可以直接双击 `Start-Game.cmd`，脚本会寻找已安装的Node。macOS/Linux运行上面的命令即可。默认地址为 `http://127.0.0.1:4173`，可通过 `node server.js --port 4180` 指定端口。

## 玩法

- USD/JPY、EUR/JPY、GBP/JPY、AUD/JPY可同时持有多空，账户盈亏与保证金统一以日元计算。
- 市价、限价、突破、OCO双向突破、止损/止盈、移动止损、部分平仓、风险预算与1%风险模板。
- 自由交易与现实20分钟连续交易局（全天开市、免保证金）；每局任务、收益/回撤/开仓保护评分、结算和PNG交易总结。
- 自由局前10模拟分钟 / 20分钟局前3现实分钟交易指导、K线历史浏览、各仓位浮盈小图、常驻其他币种简报。
- 120种随机虚构事件、六类冲击参数、共同事件跨币种联动、首次新闻与二次追踪新闻。
- 标准25倍与游戏40倍挑战规则。梭哈使用约85%可用资金，预留缓冲与费用；亏损仍可能触发强平。
- 每第三局USD/JPY包含一个随机极端行情。虚拟救急借款按游戏时间复利，支持提前还款，到期缺款结束本局。

## 四种货币独立走势

USD/JPY采用美日预期与双避险机制，EUR/JPY侧重欧洲政策/增长与能源成本，GBP/JPY具有更厚尾部和更浅流动性，AUD/JPY侧重商品/风险情绪及亚洲时段。共享日元和宏观因子使普通行情也能联动，风险厌恶阶段增强共同波动。图表显示币种特征、当前参与时段和近30分钟已实现波动；这不是方向预告。

算法、参数、迁移边界和官方研究参考见 [MODEL-V14.md](MODEL-V14.md)。模型参数为游戏设定，未由真实分钟行情拟合。

## 现实20分钟与时间平衡

- 开局选择“现实20分钟”，固定每现实秒推进一个模拟分钟；倒计时不受速度、暂停或刷新影响，到时自动撤单平仓。自由局保留1/3/10倍速和手动结算。
- 20分钟局全天连续交易、保证金占用为0、不按维持率强平；一键约10倍净值参考仓位，手动仓位不受保证金或总名义敞口约束。单笔100万单位技术上限及成交成本校验仍有效，净值耗尽会结束本局。
- 开局45个开市模拟分钟不触发普通事件，事件冷却18–35分钟，最近8主题不重复；第三局特殊行情延后到3–10现实分钟。新闻随已发生影响发布，不预告。
- 20分钟局新借款的每期改为150/300/600模拟分钟，前台节奏约现实2.5/5/10分钟；旧合同原样保留。救急窗口为有持仓、扣债净资金≤35万且账户净值为正。
- 自由局“跳过休市”逐分钟推进至下次开市，期间照常检查还款、违约、挂单到期；20分钟局一直开市，无需跳过。
- 离线期间不生成虚构补盘；返回时若已过截止，按最后保存报价结算。后台节流可能减少报价更新数，但不延长现实倒计时。
- 四币种切换行情栏移至K线上方。浏览器存档键保留，旧短局升级为新的20分钟局并在再次开始或下单时计时。

## 验证和构建

```shell
node --test tests/*.test.js
node scripts/audit-fx-v14.mjs
```

117项测试覆盖共同事件时机、币种响应、存档恢复、交易/保证金/贷款/结算和本地服务。120次完整20分钟行情长度的多币种模型模拟用于检查收益分布，不承诺收益上下限。事件说明见 [EVENTS.md](EVENTS.md)，本轮样本见 [BALANCE-V14.md](BALANCE-V14.md)。

在Windows上生成含运行环境的便携包：

```powershell
powershell -File scripts/package-windows.ps1 -NodePath C:\nodejs\node.exe -Destination C:\build\kurumi-v13
```

该打包步骤联网获取对应Node版本的官方许可证；打包后的程序运行不依赖网络。运行环境不提交到源码仓库。程序不依赖外部字体、CDN、行情API或账号登录。

## 文件

`dist/` 是离线前端；`dist/engine.js` 管理交易；`dist/market.js` 管理各市场；`dist/events.js` 是共同事件指挥器和事件库；`server.js` 是本地静态服务；`tests/` 为自动化测试。

所有新闻为游戏生成的虚构资讯。事件响应、相关性、掉期与成交深度参数未按真实市场校准，仅模拟部分现实机制，不宣称完整复制监管或券商规则。Windows启动脚本为中文；界面适配桌面、平板和手机。

Node运行时采用其官方许可证，便携包中附有 `runtime/LICENSE.node`。本仓库暂未添加游戏源码的开源许可证。


产品已统一改名为“久留美模拟器”，GitHub仓库为 `Antonnovski/kurumi-simulator`，Windows包目录为“久留美模拟器”。浏览器存档键保留旧格式以兼容原存档。

V1.0.1 使用同步增量压缩保存报价和净值，按字段表压缩持仓、订单及日志，避免长期交易存档超过浏览器常见配额；兼容读取v1/v2旧存档。保留50,000个模拟分钟的报价，保存仍写入原浏览器键。压力测试与修复记录见 STRESS-V1.0.0.md。

复现持续压力测试：`node scripts/stress-soak.mjs 7200`（约需现实两小时）。测试使用独立虚拟账户与临时本地服务，结果写入忽略提交的 `.local/stress-时间戳/`。随机请求包含预期拒单和策略分支，操作次数不等于成交笔数。两小时测试的真实计时部分顺序运行六局20分钟；引擎测试不能替代真实浏览器后台节流及渲染测试。


## V1.0.1 终端优化

增加专注交易视图与K线/下单定位，压缩顶部信息、修正挑战开关排版，完整币种简报不再覆盖交易区域。订单标题标明当前货币对。持仓/挂单/记录分页展示，每页20条；普通报价刷新复用持仓控件。长历史持仓图按像素预算保留峰谷，简报通过时间索引读取最近窗口；K线每次绘制只聚合一次。保存失败提示明确PNG只用于复盘，跳过休市后同步播放按钮。

多标签页写入会检查保存基线；检测到另一页更新后停止本页保存并提示重新载入，避免旧页退出覆盖较新的进度。同步存储检查与storage事件用于识别冲突，不承诺跨进程的原子事务。

V1.0.1 已完成现实7,202秒持续测试、4,152个随机批次、六轮真实20分钟局与117项回归。完整结果与测试范围见 [两小时压力测试报告](STRESS-V1.0.1.md)。
